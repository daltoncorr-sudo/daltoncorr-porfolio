SUNNY'S BOOKSHOP — FONTS

Every logo file in this package is outlined artwork. You don't need any font installed to use the logos.
Never retype the logo, the signature or the monogram: always use the files in Logos/.

INCLUDED HERE (free; SIL Open Font License 1.1; install them and use them for anything, including commercial work)
  Cormorant Garamond   headings and display text, 20 pt / 28 px and up; Sunny's Journal & Press is set in it
  EB Garamond          reading text: menus, newsletters, book notes, the website body
  Jost                 small labels: prices, captions, navigation, shelf talkers; capitals tracked +20 to +30
  Each family's folder has its OFL.txt. Keep it with the fonts if you pass them on.

NOT INCLUDED (commercial fonts; buy a licence only if you will set NEW text in them)
  Sailing Club, by Jen Wagner Co. (Regular and Italic)
    The type in SUNNY'S BOOKSHOP, the seal and the SB monogram.
    Buy a desktop licence for each person who will set signs, posters or newsletters in it,
    and a web licence if the website will show live text in it. Licences: jenwagner.co
  Sloop Script, by Richard Lipton (Lipton Letter Design; first published by Font Bureau)
    The lettering the signature was drawn from. The signature itself is finished artwork: use the files.
    Only needed for new script accents. Available as a desktop licence from the foundry, or through Adobe Fonts.
    Rule: never use Sloop's own capital S. The brand's S is the custom one in the signature;
    it is supplied on its own as Logos/Signature/.../SB-Signature-S. Place it by hand wherever a capital S is needed.
